LootPose Companion counts the chests you open in Fortnite Battle Royale and adds them to your LootPose account a few
seconds after each match. Unofficial. Not affiliated with Epic Games.

**Getting started**

1. Download `LootPoseCompanion.exe` below. There is no installer.
2. Run it. Windows shows "Windows protected your PC" because the file is not code-signed. Choose **More info**, then
   **Run anyway**.
3. Press **Link this PC**, check that LootPose shows the same code, and press **Link**.
4. In Fortnite: Settings, Game, Replays, Record Replays: On.

It reads only the replay files Fortnite saves in `%LOCALAPPDATA%\FortniteGame\Saved\Demos`, and sends only chest
counts. See the README for details.
